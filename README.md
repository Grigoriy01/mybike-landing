# MyBike Landing Page

A responsive promotional landing page for **MyBike** electric bicycles built with **semantic HTML5** and **modular SCSS (BEM)**.

🔗 **[Live Demo](https://grigoriy01.github.io/<имя-репозитория>/)** *(замени на актуальную ссылку)*

---

## Features

- **Mobile-First Responsive Layout:** Adaptive CSS Grid and Flexbox layout tailored for mobile, tablet (`744px+`), and desktop (`1024px+`) viewports.
- **Modular BEM & SCSS Architecture:** Clean separation of variables, mixins, placeholders, resets, and independent BEM blocks (`header`, `top-bar`, `menu`, `product`, `detail`, `contact-form`, `footer`).
- **Pure CSS Slide-Out Menu:** Smooth off-canvas navigation drawer implemented via the `:target` pseudo-class with scroll locking (`:has(.page__menu:target)`).
- **Optimized Media Assets:** Responsive images using `srcset` and modern `.webp` formats across breakpoints.
- **Fixed Reveal Footer:** Layered fixed footer effect using `isolation: isolate` and responsive viewport heights.

---

## Tech Stack

- **HTML5:** Semantic sectioning (`header`, `aside`, `main`, `section`, `article`, `footer`) and accessible form controls.
- **SCSS (Sass):** Custom breakpoint mixins, grid layout helpers, and reusable style placeholders.
- **Parcel:** Zero-config bundler for local development and production builds.
